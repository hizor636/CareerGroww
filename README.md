# 🚀 CareerGroww – AI-Powered Career Growth Platform

CareerGroww is a modern **React + TypeScript** career acceleration platform designed to turn potential into profession. It empowers students and tech professionals with expert-led courses, real-time resume extraction, skill gap detection, personalized career roadmaps, job board matching, mentor bookings, and a 24/7 AI Career Mentor chatbot.

---

## 🌟 Key Features & Modules

- **Unified Authentication & App Shell**
  - High-converting landing page with animated stats counters, curriculum highlights, student reviews, and quick account creation.
  - Seamless simulated authentication with persistent state and instant dashboard handoff.

- **Interactive Dashboard**
  - Profile strength progress, courses enrolled, jobs matched, and certificates earned.
  - Quick action feature tiles for resume analysis, gap analysis, career roadmap, and AI mentor.
  - Real-time previews of trending skills, active roadmap step, skill progress meters, and top job matches.

- **📄 Resume Analysis**
  - Drag-and-drop / file selector for PDF and DOC files.
  - Match score ring visualization, automated skill extraction meters (JavaScript, React, Node.js, HTML/CSS, Git, Python).
  - Detailed skill assessment separating strong capabilities from areas needing improvement, accompanied by actionable AI recommendations.

- **🎯 Skill Gap Analysis**
  - Multi-track selector: Full Stack Developer, Frontend Developer, Backend Developer, Data Scientist, DevOps Engineer, ML Engineer.
  - Instant calculations of skills possessed vs missing, with role readiness percentage and categorized status badges (Have it ✓, Preferred, Missing).

- **🗺️ Personalized Career Roadmap**
  - Interactive 8-step milestone tracker (HTML & CSS, JS ES6+, Git, React.js Deep Dive, Node.js & Express, MongoDB, AWS, Capstone SaaS).
  - Interactive status toggling with progress feedback.
  - Upcoming live workshops and 1:1 sessions calendar with one-click enrollment.
  - Achievement badges (JS Master, 7-Day Streak, Top Learner, Job Ready).

- **🤝 AI & Human Mentors**
  - Integrated 24/7 AI Career Coach prompt launcher.
  - Human mentor directory featuring industry engineers from Google, Amazon, Microsoft, Atlassian, Uber, and Stripe with instant booking requests.

- **🎓 Course Catalog & Learning Management**
  - Enrolled courses with active module progress tracking.
  - Comprehensive program catalog (Full Stack Web Development, Data Science & ML, AWS Cloud Practitioner, Flutter App Development, Digital Marketing, UI/UX Design).

- **💼 Job Board**
  - Top matches from tech firms (Razorpay, CRED, PhonePe, Flipkart, Swiggy, Zomato) with compensation packages, location, match score, and tech stack tags.
  - One-click application pipeline with feedback and profile boost guidance.

- **⚡ Trending Skills Analytics**
  - Real-time market demand metrics and industry growth indicators filtered by category (Technology, Security, Frontend, Analytics, Programming, Infrastructure, AI/ML).

- **🔔 Notification Center & 👤 User Profile**
  - Real-time notifications for milestone completions, job matches, and reminders with "Mark all as read".
  - Editable user profile information and customizable toggle preferences (Email Notifications, Job Alerts, Dark Mode).

- **🤖 24/7 AI Career Mentor Chatbot**
  - Floating ambient chat widget with typing indicators, quick reply shortcuts (Resume tips, Interview prep, Salary guide, Career switch), and contextual responses.

---

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4 with custom Syne & DM Sans typography and responsive dark/light palettes
- **State Management**: Reactive React state with localStorage persistence

---

## 🏃 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
